practical IT, networking, security, SIEM, ITSM, and
vulnerability-management skills.

## Purpose

The goal of this repository is to turn guided technical labs into
portfolio evidence. Each lab documents the problem being explored, the
tools used, the work performed, screenshots of key results, and
takeaways that connect the exercise to real-world IT and security work.

## Skills Demonstrated

As the series grows, this repository will showcase hands-on experience
with:

-   Network traffic capture and packet analysis
-   DNS and TCP troubleshooting
-   SIEM and log analysis
-   IT service management workflows
-   Vulnerability scanning and assessment
-   Security analysis fundamentals
-   Technical documentation
-   Evidence-based troubleshooting
